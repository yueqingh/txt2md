# txt 合并为 Markdown

Windows 10/11 小工具：把很多个 txt 文档合并成 1 个（或几个）Markdown 文档。每个 txt 的标题都会变成一级标题（`# 标题`），文档之间用横线隔开，方便 Claude 等 AI 阅读。

## 功能

- 添加文件 / 添加整个文件夹（含子文件夹）/ 直接拖入
- 排序：按文件名（自然顺序，第2章排在第10章前）/ 修改时间 / 手动上移下移
- 标题：用文件名，或用文件第一行；可带上子文件夹名
- 自动识别 UTF-8、UTF-8 带 BOM、UTF-16、GBK 编码，不会出现乱码
- 瘦身：去掉多余空行、去掉内容完全相同的文件
- 保护标题结构：正文里以 `#` 开头、纯横线、三个反引号的行会被转义，保证只有文件标题是一级标题
- 可选：生成目录；合并后超过指定大小自动拆成多个文件（不会劈开单个 txt）
- 内置日志与“复制诊断报告”按钮，出问题时点一下、粘贴给 Claude 即可

## 输出格式

```
# 文件A的标题

文件A的正文

---

# 文件B的标题

文件B的正文
```

## 使用

- 绿色版：解压 `txt2md-portable-vX.Y.Z.zip`，双击 `txt2md.exe`。
- 安装版：双击 `txt2md-setup-vX.Y.Z.exe`，按提示安装。

## 自动打包

推送到 GitHub 后，Actions 会自动测试并打包；在运行记录页面最底部的 Artifacts 下载。打版本标签（如 `v1.0.0`，必须与 `src/version.py` 里的版本号一致）后，会自动发布到 Releases。

本地运行（需 Python 3.11+）：

```
pip install -r requirements.txt
python src/app.py
```
